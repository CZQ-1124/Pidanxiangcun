# 皮蛋乡村（Pidan System）
是我们团队自主研发的面向基层医疗场景的皮肤病辅助诊疗系统，支持多角色协同（村民、家属、村医、专家），实现从早筛—辅助诊断—转诊—随访—培训的完整流程。

# 一、项目背景
基层皮肤健康管理主要存在三类问题：
基层专科诊断能力不足，易误判或延误
优质医疗资源难以下沉，转诊与会诊效率低
老龄患者多，随访与健康管理难以持续
基于此，系统依托临床真实数据资源，构建多角色协同的智能诊疗流程。 

# 二、系统角色
系统按实际使用场景划分为四类角色：
村民端（患者）
家属端
村医端
专家端
不同角色权限分离，数据按需流转。

# 三、核心功能
# 1.村民端（感知入口）
拍照上传皮损图片
勾选症状（瘙痒、疼痛、持续时间等）
AI自动生成初步分析结果
自动生成结构化病历
实现“早发现、早记录”

# 2.家属端（远程管理）
绑定老人信息
异地查看病历与AI分析结果
跟进康复与随访情况
解决老年人不会使用智能设备的问题

# 3.村医端（核心工作区）
（1）接诊初筛
输入主诉 + 图片
AI辅助诊断（结构化输出）
（2）疑难会诊（MDT）
多模型模拟多学科会诊（皮肤科/影像/病理）
输出综合诊疗建议
（3）门诊音频
录音自动转写
提取主诉并写入病历
（4）专家上转

一键提交疑难病例至上级专家
实现基层“可判断、可上转”

# 4.村医培训系统
（1）识图训练
看图判断疾病
AI即时反馈
（2）病例推演
自动生成完整病例
训练临床思维
（3）模拟门诊
AI模拟患者
对诊断过程进行评分
用于提升基层医生能力

# 5.教学病例库
浏览典型病例图像
支持结构化学习
后续支持分类检索（如皮肤镜/大体图）

# 6.专家端
（1）专家终审
查看村医上报病例
给出最终诊断
结果回传基层
（2）病例反哺
上传典型病例
进入教学库
实现“诊疗—教学”闭环

# 四、系统特点
多角色协同（患者—家属—村医—专家）
多模态输入（图像 + 文本 + 语音）
多智能体协作（MDT机制）
数据闭环（采集—诊断—随访—教学）
